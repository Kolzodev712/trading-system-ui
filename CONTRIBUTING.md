# Contributing

- Node.js 18+
- `npm install` (use the lockfile)
- `npm run generate` after proto changes (copy from `trading_system` first)
- `npm test`, `npm run build`, `npm run lint`
- Optional: `npm run test:paper-e2e` with a running paper stack

Do not commit `.env` files or production JWT secrets.
